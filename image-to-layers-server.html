How it works

Point prompts (basic masks). Add a layer group, give it a name, then click the image to select its area. The translucent overlay shows the group area; Alt+click adds a negative point to cut into it. Click a point to select its layer; Alt+click a point to delete it. Press Review & run to confirm every named group before the cutouts are written.

For object-aware masks, choose Automatic SAM. It names and groups each mask (Background, Books, Foreground, Subject, Props, …) so Studio opens with a readable segment tree instead of mask-001.

Name the layers like studio parts (eye-white-left, beard, shirt) and the auto-rig will wire them up.

Recover missing parts. Add the complete final image as the reference, then add the studio export that was aligned to it. The export's transparent (or near-white) areas are detected as holes.

Each hole becomes a new layer cut from the final image. The aligned export is kept as the visible base, so opening the recovered composition shows the whole scene again.

The magenta preview on the canvas is live and approximate; the run preview is the exact result after filtering.

Scene-guided SAM. 1) Press Describe image: a vision model looks at the whole picture and lists every object with a name, group, box and point. 2) Rename, regroup or delete objects in the list (the dashed boxes on the canvas follow). 3) Run: SAM 2 cuts each object from its box and point.

Layers keep the model's names and groups, and groups with two or more layers get their own folder under images/. layers.json lists every file.

Too coarse or too fine? Change Detail level and describe again.

Knockout background. Use the final image as the reference and drop the cut-out image whose silhouette defines the hole.

The background keeps pixels from the reference outside that silhouette, so the final background matches the original artwork exactly while removing the cut-out area.

Use a small underlap to shrink the hole slightly and hide seams; optionally keep the matching cut-out layer so the pair recomposites back to the final image.
